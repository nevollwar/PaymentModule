# Лабораторная работа №1: «Контракты в интерфейсе»

Учебный проект по дисциплине (C#, WPF, .NET 8, паттерн MVVM).  
**Выбранный сюжет:** Платёжный модуль.

---

## О проекте

Приложение демонстрирует работу контрактного программирования в графическом интерфейсе:
- **Pre (Предусловия):** проверяются на лету при вводе данных через `Guard.Requires(...)`. В интерфейсе горит индикатор: выполнены ли условия для старта.
- **Post (Постусловия):** проверяются после запуска через `Debug.Assert(...)`. В интерфейсе подтверждают корректность результата.
- **Кнопка «Показать контракт»:** открывает модальное окно с формулировками Pre/Post, побочными эффектами и граничными примерами.

---

## Операции модуля

1. **Перевод со счета на счет**
   - **Pre:** отправитель ≠ получатель, сумма > 0, баланс отправителя ≥ сумма.
   - **Post:** списано у отправителя, зачислено получателю, общий баланс системы сохранен.

2. **Пополнение счета с лимитом**
   - **Pre:** сумма > 0, сумма ≤ разовый лимит, сумма ≤ остаток дневного лимита.
   - **Post:** баланс увеличен, дневной лимит уменьшен.

3. **Оплата услуг с комиссией**
   - **Pre:** услуга выбрана, сумма > 0, баланс ≥ (сумма + комиссия).
   - **Post:** списано (сумма + комиссия), статус транзакции «Оплачено».

## Структура репозитория

- `src/PaymentApp.Domain/` — доменная логика, класс `Guard`, описание контрактов.
- `src/PaymentApp.UI/` — графический интерфейс (WPF), MVVM, карточки операций, индикаторы.
- `tests/PaymentApp.Tests/` — модульные тесты на xUnit (граничные проверки контрактов).
- `docs/` — отчет по лабораторной работе (`.docx`).

## Запуск проекта

1. Клонировать репозиторий `https://github.com/nevollwar/PaymentModule`
2. Открыть файл решения **`PaymentApp.sln`** в Visual Studio 2022.
3. Убедиться, что запускаемым проектом выбран **`PaymentApp.UI`**.
4. Нажать **F5** (или кнопку «Пуск»).
